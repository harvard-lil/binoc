# H-land Reconcile Landing Notes

## Merge

- Branch `auto/h-land-reconcile` already contained `main`; `git merge main` was a no-op.
- The branch includes the fat-binoc distribution work through `fabaf18` (`binoc` 0.2.0), including the paused publishing for `binoc-sqlite` and `binoc-stat-binary`.

## Registry and Plugin Docs

- `plugin_registry.json` is now the single plugin metadata source of truth.
- The legacy third-party plugin catalog file was removed. `docs/users/reference/third-party-plugins.md` is generated by filtering `tier: third-party` entries from `plugin_registry.json`; there are no third-party entries listed today.
- Registry entries now include a `tier` and `distribution` field so docs can state the current install path.
- `binoc-sqlite` no longer advertises a PyPI package. It is documented as a first-party opt-in rule pack: separate PyPI publishing is paused, and it is excluded from the default `binoc` 0.2.0 `bundled` feature set.
- `binoc-stat-binary` no longer advertises a PyPI package. It is documented as bundled in the default `binoc` 0.2.0 fat wheel, with separate PyPI publishing paused.
- Generated package labels now say `Rust crate` instead of `crates.io`, because the in-tree format-pack crates are workspace crates and are not necessarily published registry artifacts.
- The root README and generated install/plugin reference docs now point users to `pip install binoc` / `uvx binoc` for bundled first-party packs and avoid direct install commands for paused first-party wheels.
- ADRs that previously read like current packaging/catalog policy for `binoc[all]`, separate first-party wheels, or the deleted plugin catalog are now marked or updated as historical/superseded where this round touched them.

## Generated Docs and Snapshot Movement

- Regenerated docs with `UV_NO_CACHE=1 just docs` so Showboat used a fresh local `binoc-python` build instead of a cached uvx wheel.
- `docs/users/reference/plugin-registry.md` and `docs/users/reference/third-party-plugins.md` moved to the unified registry data.
- `docs/users/explanation/test-vectors-gallery.md` moved from 64 to 82 shared examples because the current test-vector tree has additional vectors from the reconciled branch.
- `docs/users/reference/changeset-schema.{json,md}` moved because the schema generator refreshed the current SDK schema.
- `docs/adr/README.md` and `mkdocs.yml` moved because the ADR index generator refreshed ordering/navigation.
- No insta snapshot files were intentionally updated in this round.

## Deferred Review Findings Not Fixed

- Identity model fragmentation: precomputed maps vs `DispatchResolver` vs `ItemRef.tabular_parse`; `RowIdentity` policy fields still use sentinel-as-unset; `TabularParseConfig` on `ItemRef` still contradicts the per-path ADR's "schema owned entirely by stdlib" direction.
- Suppression sentinels remain hardcoded in the writer tagger while configurable in the rule, with the default defined multiple times.
- Probe paths still swallow parse/walk errors with `let Ok(..) else continue`.
- Binary CDC still swallows IO errors via `.ok()?`.
- Core hardening remains deferred: unvalidated `LinkProposal` indices can panic; no expansion depth backstop; `cost()` charges nothing for verb names; `merge_action` collapses unknown actions to `"identical"`.
- Plugin story cleanup remains deferred where it requires API/product decisions, including the stale `binoc[all]` extra and the documented `diff(registry=...)` parameter that is not read.
