# Reference

The pages below document the full surface of binoc's APIs and configuration
formats. If you need a concrete walkthrough, see the
[tutorial](../../tutorial.md). If you want to understand the design, see the
[architecture overview](../../plugin-developers/explanation/architecture.md).

## Start by role

- **Anyone driving the CLI** — start with [CLI](cli.md).
- **Pipeline integrator** — start with
  [Changeset JSON schema](changeset-schema.md) and
  [Dataset config](dataset-config.md).
- **Python plugin author** — start with [Python API](../../plugin-developers/reference/python.md).
- **Rust plugin author** — start with [Rust SDK](../../plugin-developers/reference/sdk.md) and
  [Plugin discovery](../../plugin-developers/reference/plugin-discovery.md).
- **Plugin consumer** — start with [Third-party plugins](third-party-plugins.md).

## CLI and APIs

- [`binoc` CLI](cli.md) — every subcommand and option, generated from the
  Rust source.
- [Python API](../../plugin-developers/reference/python.md) — the `binoc` Python package, generated from
  docstrings.
- [Rust SDK](../../plugin-developers/reference/sdk.md) — `binoc-sdk` crate, generated by `cargo doc`.

## Data contracts

- [Changeset JSON schema](changeset-schema.md) — the canonical contract for
  pipeline integrators.
- [Dataset config](dataset-config.md) — every key in a dataset YAML config
  and what it does.
- [Plugin discovery](../../plugin-developers/reference/plugin-discovery.md) — entry-point spec for Python and
  Rust plugins.
- [Third-party plugins](third-party-plugins.md) — add-on plugins by file
  format; generated from `third_party_plugins.json`.
